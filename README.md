# SQL Data Analytics Practice

A structured collection of SQL practice exercises focused on developing
practical SQL skills for Data Analytics.

This repository documents my SQL learning journey, from fundamental
database and table operations to advanced analytical SQL techniques.

## 📚 Topics Covered

### SQL Basics
- Database & Table Operations
- SELECT & Filtering
- Sorting & limiting
- GROUP BY & HAVING
- String Operations
- Data Transformation
- CASE Statements
- Aggregate Functions

### SQL Intermediate
- Constraints   
- Data Integrity & Relationships
- Joins
- Set Operations
